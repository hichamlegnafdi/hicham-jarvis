# JARVIS — Gemini Edition

A Windows desktop AI assistant using:
- PySide6 GUI
- Gemini API as the AI brain
- SoundDevice + SpeechRecognition for voice input
- pyttsx3 for local text-to-speech
- Safe, allowlisted Windows actions

## 1. Install

Open PowerShell in this folder:

```powershell
py -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 2. Configure Gemini

Copy `.env.example` to `.env`:

```powershell
Copy-Item .env.example .env
notepad .env
```

Put your Gemini API key in:

```text
GEMINI_API_KEY=YOUR_KEY
```

You can change the model with `GEMINI_MODEL`.

## 3. Start

```powershell
python main.py
```

## Voice

Click the microphone button, speak for the configured number of seconds, and JARVIS will:
1. transcribe your voice,
2. run an allowlisted action when it recognizes one,
3. otherwise send the request to Gemini,
4. speak the answer locally.

Examples:
- "open chrome"
- "open youtube"
- "open downloads"
- "open notepad"
- "open calculator"
- "open settings"
- "search Google for Python"
- "open github.com"

## Important

The Gemini API requires an API key. A paid Gemini/Google subscription does not automatically mean that an API key is included; API access and billing are handled separately by Google's API platform.

Voice recognition in this version uses Google's speech-recognition service through the SpeechRecognition library, so internet access is required for voice transcription. The microphone is activated only when you press the microphone button.

This project deliberately does not execute arbitrary shell commands generated by the AI.
